# 🍔 Swiggy Sales & Customer Performance Dashboard

## 📊 Project Overview

This project presents an interactive **Swiggy Sales & Customer Performance Dashboard** built using Microsoft Excel.

The dashboard analyzes food delivery data to understand **sales performance, customer ratings, orders, food types, cities, states, restaurants, and time-based sales trends**.

The goal of this project is to transform raw data into meaningful business insights that can support data-driven decision-making.

---

## 🎯 Objectives

- Analyze overall sales and order performance
- Identify monthly, weekly, and daily sales trends
- Analyze sales across different food types
- Identify top-performing cities and states
- Understand customer rating patterns
- Compare sales, ratings, and orders across quarters
- Create an interactive dashboard using filters and slicers

---

 KPI used to show Values
